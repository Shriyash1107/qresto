❌ TROUBLESHOOTING:

   "Can't access http://10.103.72.117:5173 on phone"
   → Phone not on same WiFi
   → Check phone WiFi settings
   → Or Windows firewall blocking (see above)

   "QR scan shows site can't be reached"
   → Using old QR code with localhost
   → Create NEW QR code after the fix
   → Check destination URL has https://

   "Redirect works on computer but not phone"
   → Firewall blocking
   → Allow Node.js in Windows Firewall
   → Try disabling firewall temporarily to test
