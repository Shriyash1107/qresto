🔥 THE PROBLEM:

   Windows Firewall is blocking connections from your phone.
   That's why you get "This site can't be reached".

METHOD 1: Run the Firewall Fix Script (EASIEST) ⭐

   1. Right-click on "FIREWALL-FIX.bat"
   2. Select "Run as administrator"
   3. Click "Yes" when prompted
   4. Press any key when it asks
   5. Done! ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 2: Manual Firewall Configuration

   1. Press Windows + R
   2. Type: wf.msc
   3. Press Enter
   4. Click "Inbound Rules" on left
   5. Click "New Rule..." on right
   6. Select "Port" → Next
   7. Select "TCP"
   8. Enter ports: 5000,5173
   9. Click Next → Allow the connection → Next
   10. Check "Private" only → Next
   11. Name: QResto Servers
   12. Click Finish ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 3: Run These Commands (PowerShell as Admin)

   Open PowerShell as Administrator and run:

   netsh advfirewall firewall add rule name="QResto Backend" dir=in action=allow protocol=TCP localport=5000

   netsh advfirewall firewall add rule name="QResto Frontend" dir=in action=allow protocol=TCP localport=5173

   ⚠️  NOT RECOMMENDED FOR SECURITY REASONS

   2. Click your active network
   3. Turn OFF Windows Defender Firewall

❓ STILL NOT WORKING AFTER FIREWALL FIX?

   Check these:

   1. Phone on same WiFi as computer?
      - Check phone WiFi settings
      - Should be connected to same network

   2. Antivirus software blocking?
      - Temporarily disable antivirus
      - Test again

   3. Router blocking?
      - Some routers have AP isolation
      - Check router settings
      - Or try connecting computer directly to router

   4. Wrong IP address?
      - Run: ipconfig
      - Find your current IP address
      - Update .env file if IP changed
